# XUI y la API de cliente

La integración usa la API de línea de XUI (`player_api.php`), no un segundo panel ni un cliente distinto. El detalle de acciones, errores y referencias está en `docs/xui-integration.md`.

No hay un adaptador llamado Xprom en este código. Si el panel muestra ese nombre comercial, sigue siendo el mismo `player_api.php` configurado con `XUI_BASE_URL`. No se añade otra URL.
